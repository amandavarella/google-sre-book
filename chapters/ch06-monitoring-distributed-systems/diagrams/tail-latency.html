Chapter 6 · Worrying about your tail

One backend's 1% becomes the web page's median

A web service averages 100 ms at 1,000 requests per second, but 1% of requests take 5 seconds. To build one web page, a frontend server asks several backends for parts of the answer. A backend is a service like this one. The web page is ready only after every backend answers, so the slow 1% shows up on far more than 1% of web pages.
